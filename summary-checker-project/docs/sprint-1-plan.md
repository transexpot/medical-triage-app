# Sprint 1 Plan

**Статус:** STARTED  
**Дата старта:** 2026-11-17  
**Основание:** SPEC_DEFECT-003, 004, 005 закрыты.  
**Тесты:** 14/14 зелёные.  

## Цель спринта

Реализовать минимальный движок формальной проверки сводок
для v1.0/v1.1.

## Входит в спринт

- Загрузка сводки.
- Выполнение 7 формальных проверок.
- Классификация дефектов.
- Вычисление статуса.
- Вычисление data_complete.
- Карантин дефектных значений.
- Запись событий в журнал.
- Проверка целостности журнала.

## Не входит в спринт

- E1: согласие, доступ, оспаривание.
- E2: просмотр врачом, подтверждение, клиническое решение.
- Независимый аудит.
- Полноценный интерфейс врача.
- Обработка реальных персональных данных.

## Критерий завершения

Спринт завершён, если:

1. Все 14 тестов зелёные.
2. Движок обрабатывает валидную сводку.
3. Движок обнаруживает отсутствие даты глюкозы.
4. Движок обнаруживает неверный формат даты веса.
5. Движок обнаруживает неизвестный источник.
6. Журнал append-only.
7. verify_chain() проходит.
8. Повторный запуск даёт одинаковый результат.
